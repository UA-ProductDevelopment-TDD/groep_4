# Bittle Day Planner

Een webapplicatie die taken koppelt aan robotgedrag van de Bittle X
via seriële communicatie (Web Serial API).

## Concept
Gebruikers maken taken aan.
De Bittle reageert:
- blij bij voltooien (reward sequence)
- boos bij overdue

## Functionaliteiten
- Web Serial verbinding
- Task planner met timeline
- Skill triggers
- Motor & servo control
- Betrouwbare reward sequence met queue & delays

## Tech Stack
- React / TypeScript
- Web Serial API
- LocalStorage
- Lovable AI
